# Toon Camera preview

![Running Toon Camera app](toon-camera.png)

Actual browser screenshot of the original Asian woman avatar with local face tracking. The camera input is a public-domain NASA astronaut test photograph; it is not a user's webcam feed. The avatar, background and cel-shaded body are rendered by the app.

Browser app downloads are in `../downloads/`. The HTML contains the app and all tracking models. The ZIP is intended for an HTTPS static host. Camera permissions and browser compatibility still apply.

This branch publishes the preview and browser builds separately from ongoing source changes. It does not contain the updated app source tree or the Windows executable.
